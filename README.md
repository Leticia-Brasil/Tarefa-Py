# 🐍 Atividades Básicas de Python

Este repositório contém uma atividade acadêmica composta por **10 questões básicas de programação em Python**, desenvolvidas durante a graduação em Engenharia de Software.

O objetivo da atividade foi praticar conceitos fundamentais da linguagem e desenvolver a lógica de programação por meio da resolução de diferentes exercícios.

## 📚 Conteúdos praticados

Durante as atividades, foram trabalhados conceitos básicos de Python, como:

* 🖥️ Entrada e saída de dados
* 🔢 Variáveis e tipos de dados
* ➕ Operadores aritméticos
* 🔀 Estruturas condicionais (`if`, `elif` e `else`)
* 🔁 Estruturas de repetição
* 📋 Listas
* 🧮 Operações e cálculos
* 🧠 Lógica de programação

## 📁 Estrutura do repositório

As questões estão organizadas em arquivos individuais:

```text
📦 atividades-python
 ┣ 📜 questao01.py | if |
 ┣ 📜 questao02.py | if |
 ┣ 📜 questao03.py | if/else |
 ┣ 📜 questao04.py | if/else |
 ┣ 📜 questao05.py | if/else |
 ┣ 📜 questao06.py | if/else |
 ┣ 📜 questao07.py | if/elif/else |
 ┣ 📜 questao08.py | if/elif/else |
 ┣ 📜 questao09.py | if/elif/else |
 ┗ 📜 questao10.py | if/elif/else | Calculadora simples
```

## 🎯 Objetivo

A atividade teve como objetivo **desenvolver e reforçar conhecimentos básicos de programação e lógica**, utilizando Python para solucionar problemas propostos em sala de aula.
